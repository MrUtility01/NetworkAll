# Android Client

## باز کردن در Android Studio
1. File → Open → پوشه `android/`
2. Sync Gradle
3. Run روی گوشی/امولاتور (همان Wi‑Fi ویندوز)

## کاربرد
- آدرس سرور: `http://IP-ویندوز:5050`
- دکمه **همگام‌سازی** → `/api/sync/manifest` + pull/push
- قانون تعارض: Last-Write-Wins

## ساختار
```
app/src/main/java/com/netenc/app/
  MainActivity.kt       UI ساده + دکمه Sync
  sync/SyncClient.kt    کلاینت HTTP همگام‌سازی
  sync/SyncModels.kt    مدل‌های JSON
```

## قفل برنامه و یادآوری

- در اولین اجرا، گذرواژه محلی برنامه را تعیین کنید (حداقل ۸ نویسه). این گذرواژه پیش‌فرض ندارد و در ورودهای بعدی و پس از بازگشت از پس‌زمینه درخواست می‌شود.
- گذرواژه را فراموش نکنید؛ در این نسخه بازیابی خودکار گذرواژه تنظیم نشده است. پاک‌کردن داده‌های برنامه می‌تواند اطلاعات محلی را از بین ببرد.
- برای یادآوری یک کار، تاریخ شمسی مثل `۱۴۰۵/۰۷/۲۴` و ساعت `۱۸:۳۰` را در فرم کار وارد کنید. اجازه اعلان‌ها را بدهید. محدودیت‌های باتری و دسترسی Alarm در برخی دستگاه‌ها ممکن است روی دقت زمان اثر بگذارند.
- یادآوری مرور فاصله‌دار جدا از یادآوری زمان‌دار کارهاست.
