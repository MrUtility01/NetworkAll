# نمونه بسته Import کاربر

این پوشه یک **بسته نمونه کامل** برای تست سیستم Import است.

## مسیر

```
tools/import_samples/sample_cpu_extra/
```

## محتویات بسته

| فایل | محتوا |
|------|--------|
| `manifest.json` | مشخصات بسته + حالت merge به فصل ۱ |
| `lessons/lessons.json` | ۱ درس جدید (مدیریت حرارت CPU) |
| `notes/learning_cards.json` | ۳ فلش‌کارت با front/back |
| `questions/questions.json` | ۲ سؤال |
| `answers/answer_key.json` | ۲ پاسخ + توضیح |
| `commands/commands.json` | ۱ دستور |

## نحوه استفاده (آینده)

1. کل پوشه `sample_cpu_extra` را ZIP کنید و پسوند را به `.nacp` تغییر دهید (یا همان ZIP بگذارید).
2. در برنامه دکمه «وارد کردن بسته محتوا» را بزنید.
3. فایل را انتخاب کنید.
4. بعد از اعتبارسنجی، محتوا به فصل ۱ اضافه می‌شود.
