# بسته تکمیلی امنیت بی‌سیم — ENGINEER JOKAR

این بسته ۲۵ درس در پنج موضوع و سطوح L0 تا L4 اضافه می‌کند. شناسه‌ها مستقل از رکوردهای موجود هستند و از `lesson:ch64:wireless:...` استفاده می‌کنند.

## موضوع‌ها
1. مبانی شبکه بی‌سیم
2. استانداردها و امنیت Wi-Fi
3. طراحی و امن‌سازی WLAN سازمانی
4. ارزیابی امنیت بی‌سیم در آزمایشگاه
5. پایش، تشخیص و پاسخ به رخداد بی‌سیم

## ساختار
JSON از همان الگوی رکورد درس بسته امنیت استفاده می‌کند: `uid`, `chapter_order`, `subchapter_order`, `lesson_order`, `topic`, `level`, `summary`, `full_content`, `commands`, `examples`, `learning_objectives`, `meta`. پاسخ‌نامه در `meta.assessment.answer_key` جدا از `questions` نگهداری می‌شود.

## ادغام امن
1. از دیتابیس برنامه نسخه پشتیبان بگیرید.
2. ابتدا JSON را بررسی و UIDها و شماره ترتیب را با دیتابیس واقعی تطبیق دهید.
3. بسته را به عنوان افزونه ادغام کنید؛ دیتابیس یا curriculum را با این فایل به‌تنهایی جایگزین نکنید.
4. محتوای فنی با وضعیت `review_required` علامت‌گذاری شده و پیش از استفاده عملیاتی باید با نسخه تجهیزات، مقررات محلی و مستندات سازنده بازبینی شود.

## ایمنی
تمرین‌ها دفاعی و مجاز هستند. هیچ دستور برای شکستن کلید، جعل AP برای فریب کاربران، deauthentication یا شنود محتوای اشخاص ثالث ارائه نشده است. دستورات مشاهده‌ای ممکن است بسته به نسخه سیستم‌عامل، درایور و نام رابط متفاوت باشند.
