# ENGINEER JOKAR — فصل امنیت سایبری و هک اخلاقی

## محتویات
- `security_ethical_hacking_pack.json`: بسته مستقل 110 درس (22 موضوع × 5 سطح L0 تا L4)
- `validate_pack.py`: اعتبارسنجی ساختار بسته، UIDها و جدابودن سؤال/پاسخ
- `README_FA.md`: راهنمای ادغام امن

## ساختار پیشنهادی
فصل افزوده پیشنهادی: 64 — امنیت سایبری و هک اخلاقی. مخزن عمومی در README از 63 فصل نام می‌برد؛ شماره 64 باید قبل از واردسازی با دیتابیس واقعی تطبیق داده شود. بسته، رکوردهای موجود را حذف یا بازنویسی نمی‌کند و صرفاً رکوردهای فصل 64 را پیشنهاد می‌کند.

مبانی امنیت، قانون و مجوز، آزمایشگاه ایزوله، شبکه، Linux/Windows hardening، IAM، رمزنگاری، OSINT، اسکن مجاز، مدیریت آسیب‌پذیری، امنیت وب/API، Active Directory، وایرلس، ابر/کانتینر، SIEM، پاسخ رخداد، جرم‌یابی، پایتون دفاعی، گزارش آزمون و پروژه نهایی.

## نکته ایمنی
محتوا برای دفاع و آزمون مجاز است. تمرین‌های عملی فقط روی سامانه متعلق به شما یا محیط دارای مجوز کتبی انجام شود. از هدف‌گیری اشخاص/سامانه‌های ثالث و اختلال سرویس خودداری کنید.

## ادغام
این بسته را مستقیماً جایگزین دیتابیس نکنید. ابتدا schema و کد فعلی را بررسی کنید؛ سپس از مسیر import برنامه، در تراکنش و پس از backup، فقط رکوردهای فصل 64 را درج کنید. اسکریپت عمومی برای نوشتن مستقیم در دیتابیس اضافه نشده، چون schema نهایی برنامه باید از نسخه واقعی مخزن تأیید شود.
