# ساختار استاندارد و نهایی فصل‌ها — NetworkAll

**هدف:** یک منبع حقیقت واحد برای ویندوز و اندروید، حجم کنترل‌شده، گسترش‌پذیری بالا، بدون محتوای سنگین (ویدیو/فیلم).

این فایل **منبع حقیقت ساختار** است. هر تغییری باید با این قرارداد هماهنگ باشد.

---

## اصول طلایی (اجباری)

1. **یکسان بودن کامل ویندوز و اندروید**  
   محتوا، امکانات، ساختار درس، سوال، دستور و لاب برای هر دو پلتفرم یکسان است.  
   تفاوت فقط در لایهٔ اجرا (Flask/SQLite در ویندوز و Room در اندروید) است.

2. **بدون محتوای حجیم**  
   - ویدیو، فیلم، فایل صوتی بزرگ، تصویر سنگین ممنوع.  
   - فقط متن + JSON ساختاریافته + در صورت نیاز دیاگرام متنی/سبک (SVG یا توضیحی).

3. **منبع حقیقت واحد**  
   همهٔ محتوای آموزشی در `tools/chapters/N/` قرار دارد.  
   پوشه‌های `windows/` و `android/` فقط برای تنظیمات پلتفرم (تقریباً خالی) هستند.

4. **شناسه پایدار (UID)**  
   هر رکورد (درس، سوال، دستور و ...) باید UID یکتا و پایدار داشته باشد:  
   `ch01-lesson-001`, `ch01-q-015`, `ch01-cmd-007` و ...

5. **تولید خودکار خروجی**  
   فایل `build/chapter.json` فقط توسط اسکریپت تولید می‌شود و دستی ویرایش نمی‌شود.

## فایل‌های کلیدی و نقش آن‌ها

| فایل | نقش | ویرایش دستی؟ |
|------|------|--------------|
| `manifest.json` | متای فصل، شمارش رکوردها، وضعیت | بله |
| `lessons/base_curriculum.json` | اسکلت درس‌های پایه | محدود |
| `lessons/lessons.json` | متن غنی و درس افزوده | بله |
| `questions/questions.json` | سوالات ساختاریافته | بله |
| `answers/answer_key.json` | کلید پاسخ | بله |
| `examples/examples.json` | مثال‌ها | بله |
| `commands/commands.json` | دستورات + خروجی مورد انتظار | بله |
| `labs/labs.json` | لابراتوار | بله |
| `build/chapter.json` | بستهٔ نهایی برای اپ‌ها | **خیر** (تولید خودکار) |

## قوانین افزودن محتوا

1. درس جدید → در `lessons/lessons.json` با UID پایدار.
2. سوال مربوط به همان درس → در `questions/questions.json` با همان UID درس.
3. پاسخ → در `answers/answer_key.json`.
4. دستور و مثال و لاب همگی به UID درس لینک شوند.
5. هیچ فایل حجیم (ویدیو، mp4، فایل صوتی بزرگ) اضافه نشود.
6. بعد از تغییر محتوا، اسکریپت‌های زیر را اجرا کنید:

```bash
python scripts/assemble_chapter_packs.py --strict
python scripts/merge_content_packs_into_android.py
```

## یکسان‌سازی ویندوز و اندروید

- هر دو پلتفرم از همان فایل‌های `lessons/`, `questions/`, `commands/` و ... می‌خوانند.
- `windows/manifest.json` و `android/manifest.json` فقط مسیر منبع و تنظیمات جزئی پلتفرم را دارند.
- هیچ محتوای آموزشی تکراری در پوشه‌های پلتفرم وجود ندارد.
