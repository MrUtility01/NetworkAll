# ساختار فصل‌های NetworkAll

در این مسیر فقط پوشه‌های عددی 1 تا 68 وجود دارند. متن درس، سؤال، پاسخ، مثال، دستور، لاب، رسانه و نگاشت‌های اندروید/ویندوز هر کدام مسیر مشخص دارند.

- lessons/lessons.json: متن درس‌های افزوده
- lessons/base_curriculum.json: محتوای پایه
- questions/questions.json و questions/sources/: سؤال‌ها و آزمون‌ها
- answers/answer_key.json و answers/sources/: پاسخ‌ها و پاسخ‌نامه‌ها
- examples/examples.json: مثال‌ها
- commands/commands.json: دستورات
- labs/labs.json: سناریوها
- android/ و windows/: تنظیمات اختصاصی فصل، بدون کپی‌کردن کد مشترک
- source_archive/: منابعی که هنوز ساختاریافته نشده‌اند، بدون حذف
- build/chapter.json: خروجی سازگاری تولیدشده؛ دستی ویرایش نکنید.
