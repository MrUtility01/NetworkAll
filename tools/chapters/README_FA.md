# ساختار نهایی محتوای فصل‌ها

محتوای افزودهٔ هر فصل در تنها یک پوشهٔ اصلی نگهداری می‌شود:

- tools/chapters/chXX_slug/chapter.json: بستهٔ استاندارد افزایشی که ساخت اندروید و واردکنندهٔ ویندوز می‌خوانند.
- manifest.json: عنوان، فهرست فایل‌ها، شمار رکوردها و وضعیت بررسی.
- README_FA.md: راهنمای همان فصل.
- source_archive/: فایل‌های اولیه، بسته‌های قدیمی، پرسش‌ها، سناریوها و پاسخ‌نامه‌ها؛ این مسیر برای جلوگیری از ورود دوباره در build اسکن نمی‌شود.
- diagrams/، authoring/ و زیرپوشه‌های موضوعی: رسانه یا ابزارهای مختص همان فصل.
- tools/chapters/_shared_sources/: فقط اصل بسته‌هایی که واقعاً چند فصل را پوشش می‌دهند؛ خروجی تفکیک‌شدهٔ هر فصل در پوشهٔ خودش قرار می‌گیرد.

فهرست همهٔ ۶۸ پوشه در INDEX_FA.md ثبت می‌شود. فایل‌های منبع اصلی حذف نمی‌شوند؛ اگر بسته‌ای چندفصلی باشد، نسخهٔ اولیه برای ردیابی حفظ و نسخه‌های فصل‌به‌فصل تولید می‌شوند.

## افزودن درس جدید

در پوشهٔ فصل مناسب، محتوای درس را با فیلدهای uid، title_fa، title_en، summary، full_content، commands، examples و notes ثبت کنید. شناسه باید پایدار و یکتا باشد؛ سؤال‌ها و پاسخ‌نامه‌ها در فایل‌های جدا بمانند.

پس از تغییر منبع، از ریشهٔ پروژه اجرا کنید:

    python scripts/reorganize_chapters.py
    python scripts/export_android_index.py
    python scripts/merge_content_packs_into_android.py

محتوای پایهٔ فعلی هنوز از server/core/full_curriculum.py و server/core/extra_chapters.py ساخته می‌شود؛ تا زمان مهاجرت و آزمون مستقل، chapter.json منبع محتوای افزودهٔ فصل است و جایگزین محتوای پایه نیست. هیچ مرحله‌ای مجاز به کوتاه‌کردن یا حذف محتوای قبلی نیست.
