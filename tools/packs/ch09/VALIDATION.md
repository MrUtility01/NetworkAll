# گزارش اعتبارسنجی فصل ۹ — ARP / ICMP / TCP / UDP

تاریخ: 2026-10-13  
شاخه: `codex/android-repair-port86-20261013`

## شمارش این مرحله
- درس افزایشی: **۲۱** با UID یکتا
- مثال مستقل: **۵۰**
- سناریوی ساختاریافته: **۵۰**
- سؤال چهارگزینه‌ای: **۵۵**
- پاسخ‌نامه مستقل: **۵۵**؛ IDها و گزینه‌های پاسخ با هم تطبیق دارند
- نمودار: **۸**؛ هرکدام Mermaid source، SVG و manifest entry دارد
- منبع رسمی/استاندارد: **۱۶**
- پوشش سطوح: L0 تا L4

## کنترل‌ها
- UID درس و IDهای سؤال/سناریو/مثال یکتا هستند.
- فایل سؤال‌ها پاسخ صحیح را علامت نمی‌زند؛ پاسخ و توضیح در answer key جداست.
- سناریوها شواهد، فرضیه، اصلاح، verification و rollback دارند.
- محتوای تازه `review_required` است.

## محدودیت‌ها
1. بسته‌های منبع ایجاد شده‌اند؛ ادغام Android curriculum و ساخت APK هنوز باید اجرا و تأیید شود.
2. Mermaid/SVG ذخیره شده‌اند؛ نمایش در UI تا زمان پشتیبانی loader تضمین نیست.
3. خروجی‌ها آموزشی‌اند؛ نسخه ابزار و محیط واقعی ممکن است متفاوت باشد.
4. سناریوهای امنیتی برای تحلیل و لاب ایزوله‌اند؛ spoofing/flood روی شبکه عملیاتی اجرا نشود.
5. اعتبارسنجی ساختاری جای بازبینی علمی و آزمون واقعی را نمی‌گیرد.
