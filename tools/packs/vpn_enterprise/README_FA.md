# بستهٔ VPN سازمانی — IPsec، SSL VPN و عیب‌یابی

- مسیر JSON رسمی: tools/packs/vpn_enterprise/vpn_enterprise_ipsec_ssl_troubleshooting_pack.json
- دامنه: مفاهیم تونل، negotiation، احراز هویت، routing، firewall policy، MTU/MSS، logging و روش عیب‌یابی
- وضعیت: review_required؛ گزینه‌ها و دستورات بسته به FortiOS، RouterOS، Cisco و پلتفرم VPN متفاوت‌اند و باید با نسخهٔ واقعی تطبیق داده شوند.

قانون: تغییر VPN باید با access path جایگزین، backup، rollback و verification همراه باشد. هیچ تمرین تغییر policy یا route روی gateway در حال سرویس‌دهی بدون لابراتوار/پنجرهٔ تغییر انجام نشود.
