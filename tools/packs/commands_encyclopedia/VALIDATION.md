## اعتبارسنجی ساختاری

- هر یک از پنج بستهٔ جدید JSON معتبر دارد.
- 110 UID فرمان در بسته‌های تازه یکتا هستند.
- هر رکورد تازه، پلتفرم، نسخه/دامنه سازگاری، سطح دسترسی، نحو، پیش‌نیاز، مراحل، نمونه خروجی، نکات امنیتی، verify، rollback، منبع و ارزیابی دارد.
- ID سؤال‌ها و پاسخ‌نامه مستقل است و پاسخ درست در فایل سؤال‌ها قرار نگرفته است.
- تمام محتوای تازه `review_required` است.

اعتبارسنجی remote-file در این مرحله، ساختار و یکتایی UIDها را برای پنج بسته تأیید کرد. اعتبارسنجی یکپارچهٔ تازهٔ GitHub Actions هنوز باید اجرا و نتیجه آن ثبت شود.

## محدودیت‌ها و کارهای باز

1. هدف Cisco Routing برابر 1600 رکورد مستقل است؛ این مرحله فقط **30 از 1600** رکورد را ایجاد کرده است. فصل Cisco کامل نیست.
2. 50 مثال/سناریو/سؤال نخست از پنج پلتفرم انتخاب شده‌اند؛ همهٔ فرمان‌های دانشنامه هنوز پوشش داده نشده‌اند.
3. URLها ورودی رسمی برای مستندات پلتفرم هستند؛ بازبینی انسانی باید پشتیبانی دقیق syntax و نسخه را برای هر فرمان تأیید کند.
4. نمونه خروجی‌ها آموزشی‌اند و تضمین نمی‌کنند که هر نسخه دستگاه دقیقاً همین متن را چاپ کند.
5. هیچ‌یک از این اعداد اثبات‌کنندهٔ آزمون عملی روی سخت‌افزار واقعی نیستند.
6. خطای گزارش‌شدهٔ ساخت اندروید با دو run قبلی موفق قابل بازتولید نیست. لینک run ناموفق جدید لازم است تا خطا در log مشخص و اصلاح شود.
