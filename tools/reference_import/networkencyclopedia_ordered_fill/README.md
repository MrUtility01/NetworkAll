# Staged reference packs from NetworkEncyclopedia

These JSON files were copied from `MrUtility01/NetworkEncyclopedia/tools/packs/ordered_fill/` as a reference import set.

**Do not move them under `tools/packs/` directly.** The production pack merger can enrich an exact-title match, and older packs may overwrite newer/larger content. Instead, `scripts/import_networkencyclopedia_reference.py` validates these files, excludes existing/duplicate titles, assigns stable UIDs to unique lessons, labels imported content `review_required`, and adds it to the shared curriculum index used by Android and Windows.

The original staged files are retained unchanged here for provenance. The main content index is still generated by the normal export/merge steps first.
