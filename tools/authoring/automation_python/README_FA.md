# بستهٔ محتوای پایتون و اتوماسیون برای ENGINEER JOKAR

این بسته برای مخزن `MrUtility01/NetworkEncyclopedia` ساخته شده است. محتوای خروجی با مدل درس موجود برنامه هم‌راستاست و به‌جای ساخت جدول‌های جدید، ستون‌های آموزشی فعلی را به‌روزرسانی می‌کند.

## محتویات بسته

- `automation_python_curriculum_pack.json` — محتوای قابل‌ورود؛ ۱۳۵ درس برای ۲۷ موضوع در پنج زیرفصل.
- `build_content_pack.py` — بازتولید بستهٔ JSON از تعریف موضوع‌ها.
- `validate_pack.py` — اعتبارسنجی JSON، پوشش فصل‌ها، UIDها، بخش‌های آموزشی و جدایی پاسخ‌ها.
- `apply_content_pack.py` — پیش‌نمایش و اعمال امن محتوا به دیتابیس SQLite.
- `apply_ui_patch.py` — افزودن دو زبانهٔ جداگانهٔ «سؤال‌ها» و «پاسخ‌نامه» در رابط وب موجود.

## محدودهٔ محتوای تولیدشده

| فصل | زیرفصل | حوزه | تعداد رکورد |
|---:|---:|---|---:|
| ۲۱ | ۴ | اتوماسیون MikroTik RouterOS: Scheduler، Netwatch، Script، API، SNMP، Traffic Flow و Graphing | ۳۵ |
| ۳۵ | ۳ | اتوماسیون ویندوز/PowerShell: Remoting، ماژول AD، اسکریپت شبکه، Scheduled Jobs و DSC | ۲۵ |
| ۵۱ | ۱ | پایتون شبکه: Paramiko، Netmiko، NAPALM، Scrapli و Requests API | ۲۵ |
| ۵۱ | ۲ | اتوماسیون و زیرساخت به‌صورت کد: Ansible، Inventory، Terraform State، Git و CI شبکه | ۲۵ |
| ۵۱ | ۳ | اتوماسیون هوشمند: ChatOps، RAG، Ollama، تشخیص ناهنجاری و تولید Runbook با AI | ۲۵ |

هر موضوع در سطح‌های `L0` تا `L4` گسترش یافته است. بدنهٔ هر درس شامل اهداف، پیش‌نیازها، مقدمهٔ مفهومی، معماری، مثال، لابراتوار کنترل‌شده، عیب‌یابی، ملاحظات امنیتی، نکات پیشرفته، جمع‌بندی و واژه‌نامه است. برای هر درس چهار سؤال ارزیابی تولید شده است؛ کلید پاسخ، دلیل پاسخ صحیح و توضیح گزینه‌های نادرست از آرایهٔ سؤال‌ها جداست.

## نصب بسته در مخزن

۱. از مخزن یک نسخهٔ محلی تهیه کنید. فایل‌های این بسته را در مسیر زیر قرار دهید:

```text
tools/engineer_jokar_automation_python/
```

۲. از ریشهٔ مخزن، اعتبارسنجی محتوای JSON را اجرا کنید:

```bash
python tools/engineer_jokar_automation_python/validate_pack.py
```

۳. **ابتدا فقط پیش‌نمایش اجرا کنید.** مسیر دیتابیس را با مسیر واقعی خودتان تطبیق دهید. مقدار زیر مسیر متداول مخزن است، اما اگر برنامه از فایل دیتابیس دیگری استفاده می‌کند باید همان مسیر را بدهید:

```bash
python tools/engineer_jokar_automation_python/apply_content_pack.py --db server/data/encyclopedia.db --overwrite
```

در این حالت هیچ محتوای آموزشی نوشته نمی‌شود. ابزار باید ۱۳۵ تطبیق بر اساس شمارهٔ فصل، زیرفصل، ترتیب درس و عنوان دقیق گزارش کند. اگر عنوان یا جایگاه هر رکورد متفاوت باشد، اعمال محتوا عمداً متوقف می‌شود؛ رکوردهای نامنطبق را دستی بررسی کنید و فایل اصلی را بی‌محابا ویرایش نکنید.

۴. قبل از اعمال، سرور را متوقف کنید (`Ctrl+C`) و در صورت امکان یک کپی دستی دیگر از دیتابیس بگیرید. اسکریپت نیز پیش از تغییر، یک نسخهٔ پشتیبان با الگویی شبیه زیر می‌سازد:

```text
encyclopedia.before_automation_python_YYYYMMDD-HHMMSS.db
```

سپس فقط بعد از بررسی گزارش پیش‌نمایش، فرمان زیر را اجرا کنید:

```bash
python tools/engineer_jokar_automation_python/apply_content_pack.py --db server/data/encyclopedia.db --apply --overwrite
```

`--apply` نوشتن را فعال می‌کند و `--overwrite` به‌صورت صریح اجازه می‌دهد فیلدهای آموزشی همین ۱۳۵ درس با محتوای بسته جایگزین شوند. فیلدهای عنوان و ساختار، شناسهٔ رکوردها، UIDهای غیرخالی، فصل‌ها و زیرفصل‌ها تغییر داده نمی‌شوند. رکوردهای خارج از این ۱۳۵ درس به‌روزرسانی نمی‌شوند. `meta_json` ادغام می‌شود تا کلیدهای اختصاصی موجود حذف نشوند؛ کلید `assessment` برای این درس‌ها با سؤال‌ها و پاسخ‌نامهٔ جدید جایگزین می‌شود.

۵. برای نمایش سؤال‌ها و پاسخ‌ها در دو زبانهٔ جدا، ابتدا پیش‌نمایش patch رابط وب را اجرا کنید:

```bash
python tools/engineer_jokar_automation_python/apply_ui_patch.py --project .
```

اگر ابزار نشان داد که نقاط اتصال نسخهٔ `server/static/app.js` شناخته‌شده‌اند، patch را اعمال کنید:

```bash
python tools/engineer_jokar_automation_python/apply_ui_patch.py --project . --apply
```

این ابزار از فایل `app.js` کپی پشتیبان می‌گیرد و اگر ساختار فایل مورد انتظار نباشد، تغییر را رد می‌کند. بعد از آن سرور را مطابق روش معمول پروژه اجرا کنید. از دکمه یا endpoint «بازسازی ساختار / reseed» استفاده نکنید، مگر اینکه رفتار آن را بررسی کرده باشید؛ فرایند reseed ممکن است محتوای دست‌کاری‌شده را دوباره با محتوای اولیه جایگزین کند.

## حفاظت از سؤال و پاسخ

- `meta.assessment.questions` فقط متن سؤال و گزینه‌ها را نگه می‌دارد.
- `meta.assessment.answer_key` پاسخ، گزینهٔ صحیح، دلیل پاسخ و معیار ارزیابی را نگه می‌دارد.
- رابط وب پس از patch، این دو بخش را در زبانه‌های مستقل نشان می‌دهد.

## وضعیت اعتبارسنجی و محدودیت‌ها

- فایل JSON از نظر نحو و شناسه‌ها اعتبارسنجی می‌شود.
- تست واردسازی با یک دیتابیس آزمایشی هم‌شکل اجرا شده است: هر ۱۳۵ درس شناسایی و به‌روزرسانی شد؛ رکورد خارج از محدوده دست‌نخورده باقی ماند و نسخهٔ پشتیبان ساخته شد.
- patch رابط وب روی fixture آزمایشی با نقاط اتصال مورد انتظار اجرا شد.
- دیتابیس محلی شما در زمان تولید این بسته در دسترس نبود؛ بنابراین هنوز نمی‌توان ادعا کرد تطبیق عنوان‌ها و اجرای نهایی روی دیتابیس واقعی شما آزموده شده است. اجرای پیش‌نمایش روی همان دیتابیس شرط لازم است.
- دستورات و مثال‌های بعضی محصولات به نسخه، مدل دستگاه و سیاست امنیتی وابسته‌اند. وضعیت درس‌ها عمداً `review_required` است تا پیش از استفادهٔ عملیاتی با مستندات رسمی نسخهٔ مقصد و محیط آزمایش بازبینی شوند. بسته روی دستگاه واقعی RouterOS، Windows/AD یا تجهیزات شبکه اجرا نشده است.
