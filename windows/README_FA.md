# بستهٔ قابل‌حمل NetworkAll برای ویندوز

## پیش‌نیاز
- Windows 10/11 نسخهٔ 64 بیتی
- Python 3.11 یا جدیدتر (هنگام نصب، گزینهٔ Add Python to PATH فعال باشد)
- اتصال اولیه به اینترنت برای دریافت وابستگی‌های Python؛ اجرای بعدی پس از نصب وابستگی‌ها می‌تواند محلی باشد.

## راه‌اندازی
1. ZIP را در یک مسیر ثابت و قابل‌نوشتن استخراج کنید؛ مثلاً `C:\NetworkAll`.
2. روی `windows\Start-NetworkAll.bat` دوبار کلیک کنید.
3. بار اول محیط مجازی و وابستگی‌ها نصب و یک توکن تصادفی محلی ساخته می‌شود.
4. پنجرهٔ سرور را باز نگه دارید. رابط وب روی `http://127.0.0.1:5050` در همان رایانه قابل دسترسی است.
5. برای دسترسی گوشی، IP خصوصی ویندوز را با `ipconfig` پیدا کنید؛ در مرورگر گوشی از `http://IP-ویندوز:5050` استفاده کنید. گوشی و رایانه باید در شبکهٔ قابل‌دسترسی یکسان باشند.
6. اگر Windows Firewall درخواست دسترسی نشان داد، فقط شبکهٔ Private مورد اعتماد را مجاز کنید. در صورت نیاز یک قانون ورودی TCP/5050 فقط برای پروفایل Private ایجاد کنید؛ پورت را روی شبکهٔ عمومی یا اینترنت منتشر نکنید.
7. توکن همگام‌سازی برای تنظیم کلاینت در `server\data\sync-token.txt` ذخیره می‌شود. آن را محرمانه نگه دارید و فقط در تنظیمات اتصال برنامهٔ اندروید وارد کنید.

## رمز ورود برنامه
ورود رابط وب از همان PIN محلی پشتیبانی می‌کند که در نسخهٔ کاری تعریف شده است. متغیر محیطی `NETENC_APP_PASSWORD` برای جایگزینی PIN پیش‌فرض سرور وجود دارد؛ از ثبت رمز در Git یا اشتراک‌گذاری اسکریپت‌های حاوی رمز خودداری کنید.

## داده‌ها و بکاپ
- داده‌های سرور در پوشهٔ `server\data` نگهداری می‌شوند؛ این پوشه را حذف یا با نسخهٔ خالی جایگزین نکنید.
- قبل از ارتقا یا بازیابی، سرور را متوقف کنید و از کل `server\data` یک نسخهٔ جداگانه تهیه کنید.
- JSON بکاپ قابل‌انتقال فعلی رمزگذاری نشده است؛ آن را در مخزن Git یا فضای عمومی نگذارید.
- بازیابی را ابتدا روی یک کپی از داده‌ها آزمایش کنید. بازیابی واقعی بین ویندوز و اندروید باید با مقایسهٔ تعداد رکوردها و بازکردن چند یادداشت/کار/پیشرفت مطالعه تأیید شود.

## توقف
در پنجرهٔ سرور `Ctrl+C` بزنید. از بستن اجباری پنجره هنگام نوشتن داده‌ها خودداری کنید.

## عیب‌یابی
- اگر برنامه بالا نیامد، متن خطای همان پنجره را نگه دارید.
- اگر گوشی وصل نشد، ابتدا IP با `ipconfig`، شبکهٔ Private، پورت 5050 و فایروال را بررسی کنید.
- این بسته یک بستهٔ قابل‌حمل مبتنی بر Python است، نه فایل EXE مستقل. برای ساخت EXE مستقل باید بسته‌بندی جداگانه و آزمون روی ویندوز انجام شود.
