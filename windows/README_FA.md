# بستهٔ قابل‌حمل NetworkAll برای ویندوز

## پیش‌نیاز
- Windows 10/11 نسخهٔ ۶۴ بیتی
- Python 3.11 یا جدیدتر (گزینهٔ Add Python to PATH فعال باشد)
- اینترنت در راه‌اندازی اول برای دریافت وابستگی‌های Python

## راه‌اندازی
۱. ZIP را در مسیر ثابت و قابل‌نوشتن مانند `C:\NetworkAll` استخراج کنید.
۲. `windows\Start-NetworkAll.bat` را اجرا کنید.
۳. در اجرای اول محیط مجازی و وابستگی‌ها نصب و توکن تصادفی Sync ایجاد می‌شود.
۴. پنجرهٔ سرور را باز نگه دارید. در همین رایانه رابط وب روی `http://127.0.0.1:5050` است.
۵. رمز ورود برنامه همان PIN شخصی تعیین‌شده برای این نسخه است؛ آن را در Git یا فایل‌های عمومی ننویسید. توکن Sync با رمز ورود یکی نیست.
۶. برای اتصال گوشی، IP خصوصی ویندوز را با `ipconfig` پیدا کنید و از گوشی به `http://IP-ویندوز:5050` متصل شوید. هر دو دستگاه باید در یک شبکهٔ خصوصی قابل‌دسترسی باشند.
۷. اگر Windows Firewall درخواست دسترسی داد، فقط پروفایل Private مورد اعتماد را مجاز کنید. پورت 5050 را به اینترنت عمومی منتشر نکنید.
۸. توکن Sync در `server\data\sync-token.txt` است؛ این فایل را محرمانه نگه دارید.

## محتوای مشترک Windows و Android
بسته شامل `shared\curriculum_index.json.gz` است؛ این همان فهرست ادغام‌شدهٔ استفاده‌شده برای ساخت APK است. در نخستین بارگذاری پایگاه داده، سرور این فهرست را وارد می‌کند. وقتی فایل محتوای جدیدی داشته باشد، پیش از به‌روزرسانی پایگاه قبلی نسخهٔ پشتیبان SQLite ساخته می‌شود. import تراکنشی است؛ در خطا عملیات rollback می‌شود و دادهٔ قبلی حفظ می‌گردد. شناسهٔ درس‌ها به شناسهٔ مشترک منتقل می‌شود تا همگام‌سازی Windows و Android به یک درس اشاره کند.

## داده‌ها و بکاپ
- داده‌های سرور در `server\data` هستند؛ پوشه را حذف یا با نسخهٔ خالی جایگزین نکنید.
- بکاپ‌های خودکار به‌روزرسانی محتوا در `server\data\backups` هستند.
- قبل از هر ارتقا یا بازیابی، از کل `server\data` یک نسخهٔ جداگانه تهیه کنید.
- JSON Export/Import فعلی رمزگذاری نشده است؛ آن را در Git، فضای عمومی یا پیام‌رسان ناامن قرار ندهید.
- Restore را ابتدا روی یک کپی آزمایش کنید و تعداد رکوردها، یادداشت‌ها، وظایف و پیشرفت مرور را بررسی کنید.

## امنیت شبکه
پورت TCP/5050 را فقط در شبکهٔ خصوصی مورد اعتماد قابل دسترسی کنید. توکن Sync، پایگاه داده، و کلیدهای محلی را در ZIP عمومی یا Git منتشر نکنید.

## توقف و عیب‌یابی
- برای توقف درست در پنجرهٔ سرور `Ctrl+C` بزنید و پنجره را هنگام نوشتن داده‌ها به‌زور نبندید.
- اگر گوشی وصل نشد، IP خصوصی، فایروال Private، پورت 5050 و توکن Sync را بررسی کنید.
- اگر محتوای تازه ظاهر نشد، پیام `shared curriculum refresh` را در کنسول و پوشهٔ `server\data\backups` بررسی کنید.
- این نسخه بستهٔ قابل‌حمل مبتنی بر Python است، نه EXE مستقل؛ ساخت EXE مستقل به بسته‌بندی جداگانه و آزمون واقعی روی ویندوز نیاز دارد.
