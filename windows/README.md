# میزبان ویندوز — NetworkAll

## اجرای برنامه

1. Python 3.11 یا بالاتر نصب باشد.
2. بستهٔ پروژه را استخراج کنید و windows/start.bat را اجرا کنید.
3. start.bat ابتدا بسته‌های سازگاری هر ۶۸ فصل را از فایل‌های مرجع می‌سازد، سپس سرور Flask و SQLite را راه‌اندازی می‌کند.
4. توکن نمایش‌داده‌شده را در تنظیمات اتصال/همگام‌سازی برنامهٔ اندروید وارد کنید.

نشانی پیش‌فرض: http://127.0.0.1:5050
در شبکهٔ محلی، به‌جای 127.0.0.1 از IP میزبان ویندوز استفاده کنید. ویندوز و اندروید باید به شبکهٔ قابل‌دسترسی مشترک وصل باشند.

## توکن و پورت

توکن نصب در windows/.netenc_token ذخیره می‌شود تا اجرای بعدی همان توکن را استفاده کند. این فایل محرمانه است، نباید در مخزن ثبت شود و توسط .gitignore از Git کنار گذاشته شده است.

برای تعیین توکن دستی:

    set NETENC_TOKEN=یک-توکن-طولانی-و-تصادفی
    windows\start.bat

برای تغییر پورت، NETENC_PORT را تعیین کنید؛ برای تغییر نشانی bind از NETENC_HOST استفاده کنید. مقدار پیش‌فرض NETENC_PORT برابر 5050 و NETENC_HOST برابر 0.0.0.0 است.

## ساختار محتوای فصل‌ها

محتوای مرجع زیر tools/chapters/1/ تا tools/chapters/68/ است. هر فصل این مسیرها را دارد:

- lessons/base_curriculum.json و lessons/lessons.json: درس پایه و متن افزوده.
- questions/questions.json و questions/sources/: پرسش‌های ساختاریافته و منابع آزمون.
- answers/answer_key.json و answers/sources/: پاسخ‌ها و پاسخ‌نامه‌ها.
- examples/examples.json: مثال‌ها.
- commands/commands.json: دستورات.
- labs/labs.json و labs/sources/: لاب‌ها و سناریوهای اولیه.
- android/ و windows/: فقط تنظیمات اختصاصی پلتفرم؛ درس‌ها به‌صورت مشترک نگهداری می‌شوند.
- source_archive/: فایل‌های اولیه‌ای که هنوز به ساختار اصلی تبدیل نشده‌اند.
- build/chapter.json: فایل موقت و خودکار برای سازگاری؛ با اجرای start.bat تولید می‌شود و نباید دستی ویرایش شود.

برای ساخت و اعتبارسنجی دستی همهٔ بسته‌های فصل:

    python scripts\assemble_chapter_packs.py --strict

این بسته سورس کامل است، نه EXE مستقل. فایل پایگاه‌دادهٔ محلی و توکن شخصی را با دیگران یا در Git به اشتراک نگذارید.

## قفل ورود و فضای کاری

- رابط وب ویندوز اکنون قبل از نمایش صفحه اصلی، توکن اختصاصی نصب را می‌خواهد؛ ورود از مسیر `/workspace/login` انجام می‌شود و کوکی HttpOnly برای نشست مرورگر ثبت می‌شود.
- توکن تصادفی نصب در `windows/.netenc_token` نگهداری می‌شود. آن را با کسی به اشتراک نگذارید و در Git قرار ندهید.
- در بخش کارها، تاریخ شمسی و ساعت مثل `۱۴۰۵/۰۷/۲۴` و `۱۸:۳۰` را می‌توان ثبت کرد. اعلان مرورگر به اجازه کاربر نیاز دارد و فقط وقتی مرورگر/صفحه باز باشد قابل اتکاست؛ برای یادآوری مستقل از مرورگر از اپ اندروید استفاده کنید.
- کارها، یادداشت‌ها و رمزها از بخش فضای کاری مدیریت می‌شوند. رمزهای موجود در فضای کاری را به‌عنوان خزانه رمزنگاری‌شده سازمانی فرض نکنید.

## بسته ویندوز

Workflow مخزن، بسته کامل سورس را به‌صورت ZIP می‌سازد؛ این خروجی در وضعیت فعلی فایل اجرایی مستقل `.exe` نیست. برای اجرا به Python 3.11+ و نصب وابستگی‌ها از طریق `start.bat` نیاز است.
