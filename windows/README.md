# NetworkAll — Windows Host

## اجرا
```bat
start.bat
```

- سرور روی پورت **86**
- توکن پیش‌فرض: **09136555866** (متغیر `NETENC_TOKEN`)

```bat
set NETENC_TOKEN=رمز_دلخواه

```
