# Windows Host

## اجرا

1. Python 3.11 یا بالاتر نصب باشد.
2. فایل start.bat را اجرا کنید.
3. توکن تصادفی نمایش‌داده‌شده را در تنظیمات همگام‌سازی اندروید وارد کنید.

سرور روی پورت 5050 و رابط وب در http://127.0.0.1:5050 اجرا می‌شود. توکن نصب در فایل محلی .netenc_token کنار همین فایل ذخیره می‌شود تا بعد از راه‌اندازی مجدد ثابت بماند. این فایل محرمانه است و نباید به Git یا دیگران ارسال شود.

## تعیین توکن دستی

    set NETENC_TOKEN=یک-توکن-طولانی-و-تصادفی
    start.bat

برای تغییر نشانی bind می‌توان NETENC_HOST و برای تغییر پورت PORT را پیش از اجرا تنظیم کرد.

## ساختار محتوا

محتوای فصل‌ها از پوشه‌های tools/chapters/chXX_*/ خوانده می‌شود. base_curriculum.json درس‌های پایه و chapter.json محتوای افزوده را نگه می‌دارند؛ source_archive/ صرفاً بایگانی منابع است و دوباره وارد برنامه نمی‌شود.
