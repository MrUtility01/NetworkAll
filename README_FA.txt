NetworkAll v1.0.0 quick start
1) Extract the Windows package completely.
2) Run windows\start.bat (Python 3.11+ required).
3) Open http://127.0.0.1:86
4) The Windows server creates server\data\networkall.token on first run.
5) Enter http://IP-کامپیوتر:86 and that token in Android Settings.
6) Download Android APK only from a successful GitHub Actions artifact.
This Windows package is a Python source/host ZIP, not a standalone EXE.
See README.md, INSTALL_FA.md and docs/V1_RELEASE_AUDIT_FA.md.
