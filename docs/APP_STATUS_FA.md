# وضعیت واقعی امکانات NetworkAll v1.0.0

> نسخهٔ ۱٫۰٫۰ در این شاخه برچسب نسخهٔ ساخت است، نه ادعای تأیید همهٔ قابلیت‌ها روی دستگاه. آخرین نتیجهٔ CI و گزارش ممیزی را پیش از توزیع بررسی کنید.

## پیاده‌سازی موجود

- ویندوز: Flask + SQLite + UI وب؛ API آمار، جست‌وجو، زیرفصل‌ها و سناریوها برای UI تعریف شده و تست smoke به CI افزوده شده است.
- اندروید: Kotlin + Room + دارایی آفلاین فشرده.
- درخت درس‌ها، جست‌وجو، نمایش درس، آزمون/فلش‌کارت و سناریوها در کد وجود دارد؛ گالری دیاگرام برای اندروید و مسیر وب ویندوز طراحی شده و فایل‌های هر دو مسیر در ساخت تولید می‌شوند.
- API همگام‌سازی شامل hello/manifest/pull/push است.
- سرور از پورت پیش‌فرض TCP/86 استفاده می‌کند؛ launcher ویندوز اتصال LAN را صریحاً فعال می‌کند.
- فهرست محتوای نهایی پس از export/merge باید برای هر دو سیستم‌عامل مشترک باشد؛ Seed ویندوز نسخهٔ بسته‌شده را هنگام ایجاد دیتابیس تازه استفاده می‌کند.

## شکاف‌ها و محدودیت‌ها

| قابلیت | وضعیت صادقانه |
|---|---|

| فصل ۶۸ | باید مجموعه‌محور باشد و در CI برای نام مجموعه، عنوان و UID بررسی شود |

| Tasks / Notes | رابط و ذخیره‌سازی محلی وجود دارد؛ Sync دوطرفهٔ end-to-end را بدون آزمون نباید کامل دانست |

| نصب واقعی | CI build جایگزین نصب/اجرای واقعی گوشی نیست |

## ریسک مهم: Seed و دادهٔ قدیمی

نسخهٔ قدیمی دیتابیس ممکن است از تعداد فصل برای تشخیص Seed استفاده کند و به‌روزرسانی محتوای جدید را خودکار اعمال نکند. قبل از Reset/Clear data حتماً Export/Backup بگیرید. Seed نباید داده‌های شخصی را بی‌صدا حذف کند.

## ممیزی محتوای علمی

دستورها و خروجی‌های نمونه هنوز نیاز به اجرای جداگانه روی نسخه/فروشندهٔ هدف دارند. `source_status=review_required` باید تا زمان بررسی حفظ شود. درس‌های قالبی، متن کوتاه، عنوان نامرتبط، پاسخ‌نامهٔ ناهماهنگ و UID تکراری باید از گزارش ممیزی استخراج و اصلاح شوند.

## معیار آزادسازی

1. Workflow سبز شود: export → merge → validate → Gradle → audit داخل APK.
2. Windows ZIP از همان curriculum و با آزمون integrity تولید شود.
3. نصب تازه روی Android و اجرای اولین Seed موفق باشد.
4. تست‌ها در دو جهت Android ↔ Windows شامل ایجاد/ویرایش/حذف/تعارض/قطع شبکه/restore اجرا شوند.
5. نسخهٔ پشتیبان از دیتابیس شخصی حفظ شود.
