این برگه برای آزمون نسخهٔ آزمایشی ویندوز و اندروید است. ثبت CI یا ساخت موفق، به‌تنهایی اثبات نمی‌کند که رفتار برنامه روی دستگاه واقعی درست است.

## اقلامی که باید از همان commit دریافت شوند

- بستهٔ ویندوز: `NetworkAll-Windows-Portable.zip` و فایل checksum مربوط به آن.
- بستهٔ اندروید: `EngineerJokar-APK-v1` (APK آزمایشی debug).
- گزارش ممیزی محتوای منبع: `content-quality-audit`.
- گزارش ممیزی curriculum پس از ادغام: `active-curriculum-audit`.
- گزارش ساخت Gradle در صورت شکست: `gradle-assemble-log`.

همهٔ Artifactها باید از یک اجرای موفق Actions و یک commit واحد دریافت شوند. APK قدیمی را با بستهٔ ویندوز جدید مخلوط نکنید.

## آزمون پذیرش اندروید

- [ ] نصب APK روی گوشی آزمایشی بدون خطا.
- [ ] ورود با رمز متنی پیکربندی‌شده شامل حروف؛ کنترل اینکه ورودی فقط عددی نیست.
- [ ] رمز اشتباه رد شود؛ عدم نمایش رمز در log یا فایل عمومی.
- [ ] باز شدن فهرست درختی و نمایش فصل‌ها، زیرشاخه‌ها و درس‌ها.
- [ ] جست‌وجو و بازکردن یک درس؛ بررسی فارسی، کد، مثال و پاسخ‌نامه.
- [ ] بازشدن گالری اینفوگرافیک؛ ذخیرهٔ PNG در مسیر انتخاب‌شده و بازکردن فایل ذخیره‌شده.
- [ ] خروجی گرفتن Markdown و بازکردن آن در یک ویرایشگر/Joplin.
- [ ] صدور بکاپ JSON و بررسی اینکه شامل داده‌های حساس Vault نیست.
- [ ] بازیابی بکاپ در پروفایل آزمایشی و مقایسهٔ تعداد رکوردها.
- [ ] ثبت رفتار آفلاین، بستن و بازکردن مجدد برنامه و بررسی حفظ داده‌ها.
- [ ] آزمون همگام‌سازی فقط در شبکهٔ خصوصی مورد اعتماد و با توکن قوی؛ بررسی مسیر رفت‌وبرگشت و تعارض‌ها.

## آزمون پذیرش ویندوز

- [ ] استخراج ZIP در پوشه‌ای تازه و اجرای `windows/Start-NetworkAll.bat`.
- [ ] نصب وابستگی‌های Python طبق راهنما؛ ثبت نسخهٔ Python.
- [ ] ورود به برنامه و نمایش صحیح محتوای فارسی و درخت فصل‌ها.
- [ ] بررسی SQLite و تأیید اینکه اجرای برنامه دیتابیس موجود را پاک نمی‌کند.
- [ ] خروجی Markdown، بکاپ JSON و بازیابی در یک کپی آزمایشی.
- [ ] ذخیره و بازکردن تصویر PNG از گالری.
- [ ] اجرای سرور به‌صورت پیش‌فرض روی loopback؛ آزمون LAN فقط با Firewall محدود و توکن قوی.
- [ ] بررسی shutdown و restart و حفظ داده‌ها.

## معیارهای همگام‌سازی و ایمنی

- [ ] یادداشت، وظیفه و پیشرفت مطالعه از ویندوز به اندروید منتقل شوند.
- [ ] همان رکوردها از اندروید به ویندوز برگردند.
- [ ] رکوردهای متعارض بدون حذف خاموش داده حفظ یا طبق سیاست مستند حل شوند.
- [ ] درخواست فاقد توکن یا دارای توکن نامعتبر رد شود؛ توکن در URL query پذیرفته نشود.
- [ ] سرور به اینترنت عمومی یا port-forwarding باز نشود؛ HTTP sync فقط برای LAN مورد اعتماد است.
- [ ] بکاپ قبل از هر بازیابی موجود باشد و آزمایش بازیابی روی دادهٔ اصلی انجام نشود.
