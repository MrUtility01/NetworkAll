# NetworkAll — محتوای آموزشی و اعتبارسنجی

هر درس می‌تواند خلاصه، متن اصلی، فرمان، مثال، نکته و متادیتای ارزیابی داشته باشد؛ اما سطح عمق همهٔ درس‌ها یکسان نیست. آستانهٔ طول فقط برای پیدا کردن موارد ضعیف است و جای بررسی علمی را نمی‌گیرد.

## ویندوز

`windows\start.bat` را از Windows ZIP اجرا کنید. رابط وب روی `http://127.0.0.1:86` در دسترس است.

**احتیاط:** بازسازی دیتابیس ممکن است دادهٔ محلی را تغییر دهد. پیش از استفاده از دکمهٔ Reset/Reseed از SQLite و فایل‌های JSON شخصی نسخهٔ پشتیبان بگیرید. از `/api/reseed` یا Clear data برای رفع اشکال روزمره بدون بکاپ استفاده نکنید.

## اندروید

Workflow فایل `curriculum_index.json.gz` را از curriculum و packها تولید می‌کند. در APK تأییدشده باید ۶۸ فصل، شمار درس منطبق و ۱۰۰ فایل SVG حاضر باشند. چکِ فایل‌ها به‌تنهایی نمایش درست آن‌ها در UI یا نصب روی گوشی را اثبات نمی‌کند.

برای به‌روزرسانی نصب قدیمی، اول بکاپ بگیرید؛ Clear data همهٔ یادداشت‌ها و پیشرفت محلی را حذف می‌کند.
