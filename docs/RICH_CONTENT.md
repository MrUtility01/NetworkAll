# NetworkAll — محتوای غنی و اعتبارسنجی

هر درس شامل:

- معرفی و کاربرد سازمانی
- مفاهیم کلیدی (عمیق‌تر در L3/L4)
- مسیر Learn→Configure→Verify→Troubleshoot
- سناریوی سازمانی
- دستورات نمونه
- مثال Lab
- امنیت / Architect (سطوح بالاتر)

## ویندوز — بازسازی محتوا

```bat
cd server
python app.py
```

در UI دکمه **بازسازی ساختار** یا:

```bat
curl -X POST http://127.0.0.1:86/api/reseed
```

## اندروید

APK جدید با `curriculum_index.json.gz` نسخه ۲ (متن کامل در assets).
اگر نسخه قبلی نصب بود، پاک کنید و دوباره نصب کنید تا seed v2 اعمال شود.
