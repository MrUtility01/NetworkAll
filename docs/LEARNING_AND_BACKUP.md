# یادگیری، یادآوری و پشتیبان NetworkAll

## مطالعه و مرور

بخش Android شامل مرکز مطالعه و کد یادآوری است. زمان‌بندی اعلان‌ها به مجوز اعلان، محدودیت‌های باتری، reboot و نسخهٔ Android وابسته است؛ آن را قبل از اتکا به یادآوری‌های مهم روی گوشی آزمایش کنید.

## پشتیبان‌گیری خصوصی

**فایل دیتابیس، خروجی JSON شخصی، توکن‌ها و یادداشت‌های کاربر را به مخزن عمومی GitHub commit نکنید.** از یک دیسک خارجی یا فضای خصوصی پشتیبان‌گیری استفاده کنید.

### پشتیبان SQLite ویندوز

سرور را می‌توان برای مدت کوتاه متوقف کرد؛ یا از API پشتیبان‌گیری SQLite برای ساخت snapshot یکپارچه استفاده کرد. از ریشهٔ پروژه اجرا کنید:

```bat
python -c "import sqlite3; s=sqlite3.connect('server/data/encyclopedia.db'); d=sqlite3.connect('NetworkAll-private-backup.db'); s.backup(d); d.close(); s.close()"
```

فایل `NetworkAll-private-backup.db` را خارج از پوشهٔ سورس و در محل خصوصی نگه دارید. برای بررسی، اندازه و تاریخ فایل و امکان بازکردن آن با SQLite را کنترل کنید.

### بازیابی

1. سرور را متوقف کنید.
2. از دیتابیس فعلی یک snapshot جدا بگیرید.
3. فایل بکاپ را به مسیر دیتابیس نصب هدف منتقل کنید.
4. برنامه را اجرا و تعداد فصل/درس، یادداشت‌ها و کارها را بررسی کنید.

هرگز بکاپ تنها را روی فایل اصلی overwrite نکنید.

## پشتیبان JSON

اگر UI گزینهٔ Export ارائه می‌کند، خروجی را در مکان خصوصی ذخیره کنید. پیش از Restore بررسی کنید که قالب خروجی با نسخهٔ برنامه سازگار است و ابتدا روی یک نسخهٔ کپی آزمایش شود.

## همگام‌سازی LAN

ویندوز روی TCP/86، IP کامپیوتر و توکن per-install لازم است. توکن را فقط در Android Settings وارد کنید؛ آن را در URL، log عمومی، Git یا پیام قابل‌مشاهدهٔ دیگران قرار ندهید. Sync دوطرفهٔ همهٔ Entityها باید جداگانه آزمایش شود.
