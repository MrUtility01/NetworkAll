# ممیزی فصل‌های آموزشی NetworkAll — ۱۲ اکتبر ۲۰۲۶

## روش ارزیابی
این ممیزی بین عمق محتوا، ساختار سؤال/پاسخ، و شواهد اجرای لابراتوار تفاوت می‌گذارد. طول متن یا موفقیت ساخت برنامه به‌تنهایی تأیید علمی و عملی نیست.

## فصل‌های غنی‌سازی‌شده در این مرحله

| فصل | دامنه | یافته و اقدام |
|---|---|---|
| ۷ | TCP | پنج سطح L0–L4 و سؤالات در کف استاندارد موجود بود؛ واژه‌نامه، خروجی قابل تفسیر، عیب‌یابی و منبع رسمی در هر درس افزوده شد. |
| ۸ | UDP/QUIC | بستهٔ اصلی پنج سطح و پاسخ‌نامه دارد؛ خروجی و مسیر تشخیص اضافه شد. نسخهٔ تکمیلی هم‌UID قرنطینه و از merge فعال خارج شد. |
| ۱۹ | مبانی RouterOS | پنج سطح و پاسخ‌نامهٔ همسان؛ تفسیر خروجی و بازیابی/عیب‌یابی تقویت شد. |
| ۲۰ | Routing، Firewall و NAT | پنج سطح؛ chainها، counter، مسیر برگشت، NAT و دو WAN تکمیل عملیاتی شدند. |
| ۲۱ | QoS، VPN و HA | پنج سطح؛ baseline، MTU، queue، failover و restore criteria تقویت شد. |
| ۲۲ | Monitoring، Logging و Zabbix | پنج سطح؛ مسیر packet تا فایل و Item/Trigger، دادهٔ stale و ظرفیت دقیق‌تر شد. |
| ۲۳ | عملیات Zabbix برای MikroTik | پنج سطح؛ محاسبهٔ نرخ، reset شمارنده، Trigger/Recovery، RCA و SLO تقویت شد. |

تمام این فصل‌ها همچنان review_required و designed_not_executed هستند. برای verified شدن باید نسخهٔ محیط، خروجی واقعی، نتایج پذیرش و بازبینی انسانی ثبت شود.

## اصلاح جایگاه فصل ۱۰
بستهٔ IPv4/Subnetting به‌دلیل اشتباه در metadata در فصل ۸ قرار می‌گرفت؛ scope و شمارهٔ درس‌ها به فصل ۱۰ منتقل شد. این بسته چهار سطح L0–L3 دارد و L4 هنوز نوشته نشده، پس فصل ۱۰ کامل محسوب نمی‌شود و در وضعیت review_required باقی می‌ماند.

## کنترل بستهٔ تکراری UDP/QUIC
فایل udp_quic_engineering_ch08_deepening_v2_pack.json حفظ شد، UIDهای آن یکتا شدند، وضعیت آن quarantined و active_in_merge=false شد. اسکریپت ادغام اکنون سیاست catalog را رعایت می‌کند و آن را به نسخهٔ فعال وارد نمی‌کند.

## آزمون نسخه‌ها
رمز محلی ورود با PBKDF2 بررسی شده و نباید به شکل متن آشکار در مخزن ثبت شود. نسخهٔ ویندوز، بستهٔ Python قابل‌حمل است نه EXE مستقل؛ APK خروجی debug build است. پس از ساخت commit جدید، artifactهای همان run را دریافت کنید. پیش از حذف نسخهٔ قبلی از داده‌ها backup بگیرید. سپس درخت فصل‌ها، بازشدن درس، ذخیرهٔ PNG، Markdown export و بکاپ/بازیابی را روی دستگاه واقعی آزمایش کنید.

این برگه ممیزی ساختاری است؛ نصب روی گوشی/ویندوز کاربر و اجرای RouterOS/Zabbix واقعی هنوز باید جدا تأیید شود.
