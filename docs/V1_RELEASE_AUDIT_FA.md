## قراردادهای انتشار v1

- نام محصول: `NetworkAll`
- نسخهٔ قابل‌نمایش Android: `1.0.0`
- Android `versionCode=4` برای ارتقای نصب قبلی؛ کم‌کردن versionCode به 1 باعث خطای downgrade می‌شد.
- پورت وب/API: TCP `86`
- Application ID ثابت: `com.netenc.app`
- یک index ادغام‌شده برای ۶۸ فصل؛ UID درس‌ها باید یکتا بماند.
- Windows ZIP یک بستهٔ میزبان/سورس Python است، نه EXE مستقل.
- APK قابل‌تحویل فقط از Artifact یک اجرای سبز با `APK AUDIT OK` پذیرفته می‌شود.

## مراحل قابل‌تکرار CI

1. `scripts/export_android_index.py`
2. `scripts/merge_content_packs_into_android.py`
3. `scripts/validate_android_curriculum.py`
4. `scripts/generate_android_diagrams.py`
5. کنترل نام محصول/نسخه/پورت و توکن با `scripts/validate_release_metadata.py`
6. آزمون Seed ویندوز با `scripts/smoke_test_windows_seed.py`
7. تست Vault با `scripts/smoke_test_vault_crypto.py` و نصب وابستگی‌های سرور
8. بسته‌سازی و audit ZIP ویندوز با `scripts/package_windows_v1.py`
9. `gradle assembleDebug`
10. audit محتوای واقعی داخل APK: فصل‌ها، تعداد درس‌ها، فهرست ۱۰۰ دیاگرام
11. انتشار artifactهای Windows و Android

## آزمون‌هایی که نباید جعل یا حدس زده شوند

تا اجرای موفق پس از آخرین تغییرها در دسترس نباشد، موارد زیر **تأییدنشده** می‌مانند:

- نصب و اجرای APK روی گوشی واقعی؛
- نمایش صحیح فصل ۶۸، فهرست درس‌ها و دیاگرام‌ها در UI؛
- اولین Seed و به‌روزرسانی دیتابیس قدیمی بدون از دست رفتن یادداشت/پیشرفت؛
- اتصال Android به IP ویندوز روی پورت ۸۶؛
- Sync دوطرفهٔ create/update/delete و مدیریت تعارض؛
- backup و restore واقعی؛
- اعلان زمان‌بندی‌شده پس از reboot/Doze و تقویم شمسی در هر دو سیستم‌عامل.

**تصمیم انتشار:** این شاخه خروجی‌های کاندید v1.0.0 می‌سازد. «نسخهٔ نهایی تأییدشده» فقط پس از سبز شدن کنترل بسته و اجرای smoke-testهای بالا اعلام می‌شود.
