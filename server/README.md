# دایرةالمعارف شبکه — نسخه وب v1

## ویژگی‌ها
- **۶۸ فصل کامل** از Blueprint (نه ساختار قدیمی ۱۴ فصلی)
- **بارگذاری تنبل:** فقط فهرست فصل‌ها اول لود می‌شود؛ زیر‌فصل و درس با کلیک
- رابط **راست‌چین فارسی** در مرورگر
- حداقل ۱۵۰ سناریوی مشترک عیب‌یابی + سناریوهای Capstone سازمانی
- جستجو در عناوین و محتوا

## اجرا روی ویندوز

```bat
cd /d مسیر\NetworkEncyclopediaWeb
python -m pip install -r requirements.txt
python app.py
```

مرورگر را باز کنید:

```text
http://127.0.0.1:5050
```

اولین اجرا ساختار (~۵۰۰۰ درس عنوان‌دار) را یک‌بار می‌سازد؛ بعد سریع است.

## API
- `GET /api/chapters` — فقط فصل‌ها
- `GET /api/chapters/<id>/levels` — زیر‌فصل‌های یک فصل
- `GET /api/levels/<id>/lessons` — درس‌های هر زیر‌فصل
- `GET /api/lessons/<id>` — محتوای یک درس
- `GET /api/scenarios` و `GET /api/scenarios/<id>` — فهرست و جزئیات سناریوها
- `GET /api/stats` — آمار بانک آموزشی
- `GET /api/search?q=...` — جست‌وجو
- `GET /resources/network-book.docx` — دانلود جزوهٔ شبکه از پوشهٔ اصلی
- `GET /resources/packet-journey-reference.png` — تصویر مرجع مسیر پکت
- `GET /api/levels/<id>/lessons` — درس‌های یک سطح
- `GET /api/lessons/<id>` — محتوای درس
- `GET /api/scenarios` — Capstoneها
- `POST /api/reseed` — بازسازی کامل

## نکته
محتوای متنی عمیق هر درس بعداً با AI پر می‌شود؛ **ساختار و عنوان‌ها از ابتدا کامل‌اند.**


## به‌روزرسانی هم‌زمان اندروید و وب
- تاریخ نمایشی رابط‌ها شمسی است؛ timestampهای داخلی همچنان ISO-8601 باقی می‌مانند تا Sync دقیق بماند.
- `tools/packs/scenarios/scenarios_150.json` بستهٔ مشترک ۱۵۰ سناریوی عملی است و همان فایل در Android assets قرار دارد.
- دکمهٔ «مرکز یادگیری» شامل آمار مرور، دسترسی به سناریوها، آزمون کوتاه و جزوهٔ جامع است.
- «آزمایشگاه پکت» یک شبیه‌ساز آموزشی مرحله‌ای از DNS/ARP/TCP SYN تا Routing، NAT/PAT، SYN-ACK و TLS است؛ داده‌های نمایشی نمونه‌اند و capture زنده محسوب نمی‌شوند.
- APIهای آموزشی read-only عمومی‌اند تا وب‌کلاینت بدون توکن Sync بتواند محتوا را بخواند؛ APIهای Sync همچنان توکن می‌خواهند. بازسازی بانک فقط از میزبان محلی یا با توکن معتبر مجاز است.
